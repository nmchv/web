# Персональный сайт Алексея Немичева (nmchv.ru)

Статический сайт на [Astro](https://astro.build). Публикуется на GitHub Pages, сервер не нужен.

## Запуск
```bash
npm install
npm run dev       # разработка, http://localhost:4321
npm run build     # проверка типов (astro check) + сборка в dist/
npm run preview   # просмотр собранного сайта
```

## Где менять контент
Все тексты и данные лежат в `src/data/ru/`, компоненты их только выводят.

| Файл | Что внутри |
|---|---|
| `profile.ts` | имя, подпись, описание, «Обо мне», фото |
| `projects.ts` | проекты (карточки строятся автоматически) |
| `education.ts` | образование и опыт (пусто, секция скрыта) |
| `contacts.ts` | контакты (пусто, секция и пункт меню скрыты) |
| `directions.ts` | направления деятельности |
| `ui.ts` | подписи интерфейса, SEO-заголовок и описание |

**Добавить проект:** новый объект в `projects.ts` (`url` не обязателен, без него карточка без ссылки). Свою картинку положите в `public/` и укажите в поле `image`.
**Фото:** положите файл в `public/` и раскомментируйте `photo` в `profile.ts`.
**Цвета:** CSS-переменные в начале `src/styles/global.css`.

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub и загрузите проект в ветку `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Каждый push в `main` запускает `.github/workflows/deploy.yml`: установка, `npm run build`, публикация. При ошибке сборки публикации не будет.
4. Домен: файл `public/CNAME` уже содержит `nmchv.ru`. В Settings → Pages → Custom domain введите `nmchv.ru` и включите Enforce HTTPS.
5. DNS у регистратора (делает владелец домена): для apex-домена четыре A-записи на `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`; для `www` CNAME на `<ваш-логин>.github.io`. Актуальные адреса сверьте в документации GitHub Pages.

Поддомены `wiki.` и `geotrainer.` настраиваются отдельно и сайт не затрагивают.

## Языковые версии
Русская версия опубликована в корне сайта; английская, французская, испанская, корейская, китайская, японская, немецкая и шведская — на `/en/`, `/fr/`, `/es/`, `/ko/`, `/zh/`, `/ja/`, `/de/` и `/sv/`.
Переводы интерфейса и проектов находятся в `src/data/<язык>/`; общие данные проектов, контактов и образования наследуются из русской версии.
